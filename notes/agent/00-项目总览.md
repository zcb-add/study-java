# 多功能 AI Agent 智能助手 · 项目总览

> 完成时间：2026-08-30
> GitHub：https://github.com/zcb-add/agent-assistant
> 一句话：一个**会调用工具的 AI 助手**，从"只会聊天"升级到"能自主完成任务"。

---

## 这个项目是干什么的？

普通的聊天 AI 只能"说话"，而这个 Agent 能**动手做事**：

| 你说 | 它做什么 |
|---|---|
| `算一下 (1+2)*3**2` | 调用计算器工具，精确算出 27 |
| `查询北京的天气并保存到文件` | **自主连续调用**天气工具 → 文件工具 |
| `记住我住在乌鲁木齐，叫我小阳` | 把偏好写进数据库（长期记忆） |
| `（新建会话）我叫什么？` | 从长期记忆里回忆出来 |

**本质**：给大模型装上了"手"（工具）和"脑"（推理循环）和"记忆"（数据库）。

## 技术栈

| 层 | 用的什么 | 为什么 |
|---|---|---|
| 语言 | Python 3.13 | AI 生态最成熟，`requests` 一行调 API |
| 大模型 | DeepSeek API（deepseek-v4-flash）| 国内可用、便宜、Function Calling 支持好 |
| 推理 | **手写 ReAct 循环**（不依赖 LangChain）| 为了彻底搞懂原理，面试能讲透 |
| 工具 | Function Calling 机制 | 模型返回"想调用哪个工具+参数"，我们执行 |
| 界面 | Streamlit | 一个 `streamlit run app.py` 就有 Web UI |
| 存储 | SQLite（Python 自带）| 零安装，一个文件存全部数据 |

## 目录结构（每个文件是干嘛的）

```
agent-assistant/                  # 项目根（独立 git 仓库）
├── app.py                Streamlit 界面入口（多会话+流式）
├── cli.py                命令行入口（终端也能聊）
├── config.py             配置中心（API 地址/模型名/路径，全在这改）
├── agent/                ★ Agent 核心
│   ├── core.py           ReAct 循环（思考→行动→观察→回答）★ 最重要
│   ├── llm.py            调大模型（普通 + SSE 流式）
│   ├── messages.py       短期记忆裁剪
│   └── system_prompt.py  系统提示词（自动注入长期记忆）
├── tools/                ★ 工具层
│   ├── __init__.py       工具注册表（加工具只改这登记一行）
│   ├── file_tools.py     创建/读取/列出文件
│   ├── compute_tools.py  计算器（安全版）/ 时间
│   ├── web_tools.py      搜索 / 抓网页
│   ├── weather_tools.py  天气
│   └── memory_tools.py   记住/回忆用户偏好
├── storage/              ★ 数据层（SQLite）
│   ├── db.py             建表 + 连接
│   ├── memory.py         长期记忆（preferences 表）
│   └── sessions.py       多会话（sessions + messages 表）
├── tests/                pytest 单元测试
└── generated_files/      文件工具的工作目录（安全边界）
```

## 怎么运行

```bash
cd D:\Dev\agent-assistant
# 先确保 .env 里填了 API Key（复制 .env.example 改一下）

# 图形界面（推荐，好看）
streamlit run app.py

# 命令行（轻量，方便调试）
python cli.py
```
