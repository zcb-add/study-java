# 2026-08-28 第二课：方法（函数）

## 为什么需要方法？

- 场景：5 个班都要算最低分 / 不及格人数
- 不写方法 → 得把代码复制 5 遍，又臭又长，改一处要改 5 处
- **方法 = 把"能重复用的逻辑"装进有名字的盒子，用的时候喊名字**

## 方法有 4 个零件（以 getMin 为例）

```java
static int getMin(int[] arr) {
    int min = arr[0];
    for (int i = 1; i < arr.length; i++) {
        if (arr[i] < min) {
            min = arr[i];
        }
    }
    return min; // 把结果交回去
}
```

| 零件 | 意思 |
|------|------|
| `static` | main 里直接调用就得写（见下方踩坑） |
| `int`（返回值类型） | 方法会还给你一个整数 |
| `getMin`（方法名） | 盒子上的名字，喊它就用它 |
| `int[] arr`（参数） | 调用时必须把数组传进来 |
| `return min` | 把结果交回去 |

## 调用的样子

```java
System.out.println("最低分：" + getMin(class1));
// getMin(class1) 会算出一个 int，再拼进字符串打印
```

## 两个关键字

- **`static`**：static 方法里只能直接调 static 方法。
  main 是 static，所以想让 main 喊它们，就得加 static。
  > 踩坑实录：不加 static → 编译报错"无法从静态上下文中引用非静态方法"。亲眼见过就不会忘了。
- **`void`**：表示"不返回任何值"，只干活（比如只打印）。void 方法里不用写 `return`。

## 返回值 vs void

- `int getMin(...)` → 有返回值，调用处可以拿这个数去用 / 打印
- `void printAvg(...)` → 没返回值，调用处喊一声，它自己就打印了

## 小数怎么算（除法陷阱）

- `int / int` 结果还是 `int`，小数会被砍掉
- 让除法里至少有一个 `double`，结果才带小数
  ```java
  double sum = 0;          // 用 double 累加
  sum += score;
  double avg = sum / arr.length;  // sum 是 double，除出来就是小数
  ```
